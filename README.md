# Виселица — Ғаламтор

Қазақ тіліндегі қарапайым «Виселица» ойыны. Бір ғана сөз — **ҒАЛАМТОР**.
Сыртқы кітапханалар жоқ: таза HTML + CSS + JavaScript.

## Не бар

- Тақырып, санат («Ғаламтор»), дар суреті және қате санағы
- Жасырын сөздің 8 шаршысы
- Қазақ әліпбиінің экрандық пернетақтасы (42 әріп) + өз клавиатураңыз
- 7 қателік — ойын бітеді; барлық әріпті тапсаңыз — жеңіс
- «Қалай ойнау керек» және «Бұл ойын туралы» мәтіндері
- Жеңіс/жеңілістен кейін «Қайта ойнау» түймесі (немесе Enter)

Артық функциялар жоқ: режимдер, тіл таңдау, деңгей, таймер, рейтинг жоқ.

## Іске қосу

`index.html` файлын браузерде ашыңыз. Немесе:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Файлдар

- `index.html` — бет құрылымы
- `styles.css` — ашық тақырып, қарапайым дизайн, адаптив
- `script.js` — ойын логикасы (сөз `WORD` айнымалысында, `MAX_MISTAKES = 7`)
