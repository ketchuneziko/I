# Ғаламтор — сайт-визитка

«Ғаламтор» интернет-провайдерінің бір беттік сайт-визиткасы. Барлық мәтін қазақ тілінде.

## Іске қосу

```bash
python3 -m http.server 8000
```

Содан кейін браузерден `http://localhost:8000` ашыңыз.

## Құрылымы

- `index.html` — беттің құрылымы (басты бет, қызметтер, тарифтер, біз туралы, байланыс)
- `styles.css` — қараңғы тақырып, градиенттер, толық адаптив
- `script.js` — мобильді мәзір, анимациялар, телефон маскасы және форма валидациясы

Сыртқы кітапханалар қолданылмайды — сайт таза HTML, CSS және JavaScript-тен тұрады.
