# Ғаламтор — Виселица ойыны

Қазақ тіліндегі «Виселица» (hangman) ойыны. Негізгі сөз — **ҒАЛАМТОР**.
Сыртқы кітапханалар қолданылмайды: таза HTML + CSS + JavaScript.

## Қалай ойнау керек

1. Экрандағы қазақ әріптерінің пернетақтасынан (немесе өз клавиатураңыздан) әріп таңдаңыз.
2. Дұрыс әріп сөзде ашылады.
3. Қате әріп сайын виселицаға бір бөлік қосылады — барлығы **6 қателік** рұқсат.
4. Барлық әріптерді 6 қателікке жетпей тапсаңыз — **жеңіс** (конфетти мен есепке +1).
5. 6 қателік болса — **жеңіліс**, дұрыс сөз ашылады. «Келесі сөз» түймесімен жалғастырыңыз.

Жеңіс/жеңіліс саны мен қатар жеңістер браузерде (localStorage) сақталады.
«Enter» — ойын біткенде келесі сөзге өту.

## Іске қосу

`index.html` файлын браузерде ашу жеткілікті. Немесе:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Басқалар да аша алатындай етіп жариялау (GitHub Pages)

1. https://github.com/ketchuneziko/I/settings/pages ашыңыз
2. **Build and deployment → Source** тармағында **GitHub Actions** таңдаңыз
3. **Actions** бетіне өтіп, «Сайтты жариялау (GitHub Pages)» жұмысын қайта іске қосыңыз (Re-run all jobs)

Сайт мекенжайы: **https://ketchuneziko.github.io/I/**

## Файлдар

- `index.html` — бет құрылымы (виселица суреті, сөз ұяшықтары, пернетақта)
- `styles.css` — қараңғы дизайн, анимациялар, адаптив
- `script.js` — ойын логикасы, сөздер тізімі, есеп, конфетти, клавиатура
- `.github/workflows/pages.yml` — автоматты жариялау

## Сөздерді өзгерту

`script.js` ішіндегі `WORDS` массивін өңдеңіз:

```js
{ word: "ҒАЛАМТОР", hint: "Бүкіл әлемді байланыстыратын цифрлық желі" }
```
